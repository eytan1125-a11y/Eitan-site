# האתר של איתן שלם — צילום וידאו

האתר מוכן. נשאר רק לחבר אותו ל-Firebase (אחסון האתר + מסד הנתונים) ולהעלות אותו לאוויר.

## מה עושים עכשיו

1. מורידים את כל התיקייה הזו למחשב.
2. פותחים אותה ב-Claude Code (או כל Claude עם גישה לתיקייה).
3. כותבים לו: **"תחבר את האתר ל-Firebase ותעלה אותו לאוויר לפי CLAUDE.md"**.

Claude ישאל כמה שאלות (איזה חשבון Google ינהל את האתר, אם כבר יש פרויקט Firebase), ויבקש ממך להתחבר בדפדפן פעם אחת. זה הכול.

## מה יש באתר

- דף ראשי: פתיח, אודות, תיק עבודות (סרטוני יוטיוב), מחירון, בדיקת זמינות לתאריך, וטופס הצעת מחיר שנפתח בוואטסאפ.
- **דף ניהול** (`/admin`): נכנסים עם חשבון Google, מסמנים תאריכים תפוסים, ורואים את כל מי שמילא את הטופס — גם מי שלא לחץ "שלח" בוואטסאפ.
- גולשים יכולים לבדוק אם תאריך מסוים פנוי, אבל לא רואים את כל היומן.

## דברים שכדאי להחליט

- **תמונת הרקע בראש הדף** — כרגע זו תמונה מתוך הקליפ הראשון. כדאי לשלוח ל-Claude תמונה רחבה ויפה מאירוע.
- מחירים, טקסטים וסרטונים — Claude יכול לשנות כל אחד מהם לפי בקשה.
- דומיין משלך (למשל eitanshalem.co.il) — אפשר לחבר אחרי שהאתר באוויר.

## תצוגה מקדימה בלי אינטרנט

פותחים את התיקייה `public` דרך שרת מקומי (Claude יודע לעשות את זה). עד ש-Firebase מחובר, בדיקת הזמינות עובדת על רשימת תאריכים לדוגמה.
